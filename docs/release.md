# Play 스토어 출시 준비

코드로 해 둔 것과, 계정 주인이 직접 해야 하는 것을 나눠 적는다.

## 이미 되어 있는 것

| 항목 | 상태 |
|---|---|
| 대상 API 수준 | Android 16 (API 36). 2026년 8월 31일부터 새 앱의 필수 조건 |
| 최소 지원 | Android 7.0 (API 24) |
| 앱 ID | `com.yujin.moa` (출시 후에는 바꿀 수 없다) |
| 아이콘·스플래시 | 적응형 아이콘 포함. 원본은 `assets/` |
| 서명된 AAB 빌드 | Actions의 **Release AAB** (아래 1번의 키가 있어야 돈다) |
| 버전 | 이름은 `package.json`의 `version`, 코드는 빌드 번호로 자동 증가 |
| 권한 | 인터넷, 알림(사용자가 켤 때만 요청). 정확 알람 권한은 뺐다 |
| 개인정보 처리방침 | `docs/privacy.md` (운영자 이름과 연락처를 채워야 한다) |
| 기록 저장 | 앱 전용 폴더의 파일. 내보내기·가져오기·전체 삭제 제공 |

## 직접 해야 하는 것

### 1. 업로드 키 만들기 (한 번만)

Java가 있는 컴퓨터에서:

```bash
keytool -genkeypair -v -keystore moa-release.jks -alias moa -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 moa-release.jks > moa-release.jks.b64     # macOS는 base64 -i moa-release.jks
```

GitHub 저장소 Settings → Secrets and variables → Actions → Secrets에 넣는다.

| 이름 | 값 |
|---|---|
| `MOA_KEYSTORE_BASE64` | `moa-release.jks.b64` 파일의 내용 |
| `MOA_KEYSTORE_PASSWORD` | 키 저장소 비밀번호 |
| `MOA_KEY_ALIAS` | `moa` |
| `MOA_KEY_PASSWORD` | 키 비밀번호 |

`moa-release.jks`와 비밀번호는 안전한 곳에 따로 보관한다. 저장소에 올리지 않는다. Play 앱 서명을 쓰면 이 업로드 키를 잃어도 Google에 요청해 바꿀 수 있다.

### 2. Play Console 계정

- [Play Console](https://play.google.com/console) 가입 (등록비 US$25, 본인 확인 필요).
- **개인 계정은 프로덕션 출시 전에 비공개 테스트를 해야 한다: 테스터 12명 이상이 14일 연속 참여.** 그 뒤 프로덕션 액세스를 신청하고 심사를 받는다. 처음 출시까지 3주쯤 잡는다.
- 유학 재류자격으로 일본에 있다면, 유료 판매나 수익 활동을 시작하기 전에 자격외활동허가 범위를 확인한다. 무료 앱으로 올리는 것부터 시작하는 편이 안전하다.

### 3. 개인정보 처리방침 URL

`docs/privacy.md`의 `[운영자 이름]`, `[연락처 이메일]`을 채운다. Play Console에는 누구나 열 수 있는 주소를 넣어야 한다.

- 가장 쉬운 방법: 저장소 Settings → Pages에서 `moa` 브랜치의 `/docs`를 게시하면 `https://<계정>.github.io/plan3/privacy` 주소가 생긴다.
- 주소를 바꾸면 `src/screens/Settings.tsx`의 `PRIVACY_URL`도 같이 고친다.

### 4. AAB 만들어 올리기

1. `package.json`의 `version`을 올린다 (예: `1.0.0`).
2. Actions → **Release AAB** → Run workflow → Artifacts의 `app-release-aab`를 받는다.
3. Play Console → 테스트 → 비공개 테스트 → 새 버전 만들기에 올린다.

### 5. Play Console 양식

**데이터 보안** (AI 서버를 연결해 출시하는 경우의 초안. 최종 판단은 본인이 약관을 확인하고 한다)

| 질문 | 답 |
|---|---|
| 데이터를 수집하거나 공유하나요? | 예 (AI로 알아듣기를 켠 사용자의 문장이 기기 밖으로 나간다) |
| 수집 항목 | 앱 활동 → 기타 사용자 제작 콘텐츠 |
| 수집 목적 | 앱 기능 |
| 선택 사항인가요? | 예 (사용자가 켤 때만) |
| 전송 중 암호화 | 예 |
| 삭제 요청 방법 | 서버에 저장하지 않음. 기기 기록은 앱에서 삭제 |
| 제3자 공유 | Gemini를 **유료 키**로 쓰면 Google은 처리 위탁자라 공유에 해당하지 않는다. 무료 한도 키는 Google이 내용을 제품 개선에 쓰므로 출시 버전에 쓰지 않는다 |

AI 서버 없이 출시하면 "데이터를 수집하지 않음"으로 답할 수 있다.

**그 외**

- 앱 액세스 권한: 로그인 없음, 모든 기능 제한 없이 사용 가능.
- 광고: 없음.
- 콘텐츠 등급: 설문 작성 (폭력·성적 내용 없음, 사용자 간 소통 없음).
- 타겟 연령: 13세 이상.
- 건강 앱 신고: MOA는 의료·건강 앱이 아니다. 스토어 설명에 ADHD 같은 질환의 개선을 내세우지 않는다.

### 6. 스토어 등록정보

문구 초안은 `docs/store-listing.md`. 직접 준비할 그림:

- 앱 아이콘 512×512: `assets/icon-only.png`를 줄여서 사용
- 그래픽 이미지 1024×500
- 휴대전화 스크린샷 2장 이상 (실제 기기에서 찍은 것)

## 출시 전에 실제 기기에서 확인할 것

이 저장소의 자동 검사는 기록 로직과 브라우저 화면까지만 본다. 아래는 폰에서 직접 봐야 한다.

- [ ] 상태 표시줄·내비게이션 바와 화면이 겹치지 않는가 (Android 15 이상은 화면이 가장자리까지 그려진다)
- [ ] 키보드가 올라올 때 입력창이 가려지지 않는가
- [ ] 뒤로가기: 설정·시계 닫기 → 첫 화면 → 홈 화면으로 나가기
- [ ] 앱을 완전히 껐다 켜도 기록이 남는가
- [ ] 내보내기가 공유 창을 여는가, 가져오기가 되는가
- [ ] "먼저 말 걸기"를 켜고 3시간 뒤 알림이 한 번 오는가, 자는 동안은 안 오는가
- [ ] AI로 알아듣기: 켰을 때 대답이 오는가, 비행기 모드에서 메모로 남는가
- [ ] 작은 화면과 큰 글꼴 설정에서 글자가 잘리지 않는가

## 아직 스토어 품질에 못 미치는 것

- 한국어만 지원한다. 일본 출시에는 일본어 번역이 필요하다.
- 기기 간 동기화와 클라우드 백업이 없다 (Android 자동 백업과 수동 내보내기만).
- 어두운 테마가 없다.
- 화면 읽기 프로그램에서 격자는 그림 하나로만 읽힌다.
- 서버에 앱 검증이 없어 주소를 아는 사람은 누구나 부를 수 있다 (요청 한도로만 막는다).
