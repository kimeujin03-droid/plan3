# MOA (모아)

말하거나 칸을 문질러서 하루를 기록하는 개인 라이프로그 앱. React + Vite로 만들고 Capacitor로 Android APK를 만든다.

예전 Life Log Planner 코드는 `legacy/`에 그대로 남겨 두었다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 모아 | 첫 화면. 지금 하는 일, 자주 쓰는 말 버튼, 모아의 대답과 되돌리기 |
| 오늘 | 24시간 격자(한 시간 = 가로 6칸). 계획·실행·지우개를 골라 문질러 칠한다 |
| 시계 | 진행 중인 일의 시계, 집중도 1~5, 같이 하는 일 |
| 기록함 | 하려던 일(말한 날 → 시작), 계획이 바뀐 흐름, 내가 한 말 원문 |
| 돌아보기 | 주간 적어둔 시간, 요일별 집중도, 하려던 일의 시작까지 걸린 기간 |
| 설정 | 활동 이름, 먼저 말 걸기 알림, 내보내기·가져오기, 전체 삭제 |

## 격자 규칙

- 계획: 칸 전체를 연하게 채운다. 칸당 1개.
- 실행 1개: 칸 높이의 80%.
- 실행 2개: 둘째가 아래 30%. 한 칸에 2개까지이고 세 번째를 칠하면 둘째가 바뀐다.
- 시간은 분·초 그대로 저장하고, 10분 칸은 보여주는 방식일 뿐이다 (`src/lib/intervals.ts`).

## 모아가 알아듣는 말

AI 서버 없이 규칙으로 해석한다 (`src/lib/parser.ts`). 못 알아들은 말은 메모로 남고, 모든 말은 원문 그대로 쌓인다.

| 말 | 결과 |
|---|---|
| `과제 시작할게` | 타이머 시작 (동시에 2개까지) |
| `끝났어`, `수업 끝났어` | 타이머 종료 |
| `논문 써야지` | 하려던 일로 기록 (시작과 구분) |
| `하기 싫어` | 기분만 기록, 계획은 그대로 |
| `아까 14시부터 15시 반까지 알바 했어` | 지난 시간 채우기 |
| `나 잘게` / `일어났어` | 수면 시작·종료 |
| `집중도 4`, `피로도 80` | 점수 기록 |
| `말 걸지 마` | 먼저 말 걸기 끄기 |

## 개발

```bash
npm install
npm run dev      # 브라우저에서 확인
npm test         # 기록 로직 테스트
npm run build    # 타입 검사 + 빌드
```

## APK 받기

`moa` 또는 `main` 브랜치에 푸시하면 GitHub Actions(`Android CI`)가 디버그 APK를 만든다. 저장소의 Actions 탭 → 최근 실행 → Artifacts의 `app-debug-apk`를 내려받아 설치한다. 자세한 순서는 `GITHUB_APK_BUILD.md`.

앱 ID는 `com.yujin.moa`라서 예전 앱과 따로 설치된다.

## 아직 없는 것

- 기록은 이 기기 안(localStorage)에만 저장된다. 백업은 설정의 내보내기로 직접 한다.
- GPS, 영수증·가계부, 사진, 키링 연동은 없다.
- "먼저 말 걸기" 알림은 실제 기기에서 확인하지 못했다.
