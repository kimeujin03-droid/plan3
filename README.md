# MOA (모아)

말하거나 칸을 문질러서 하루를 기록하는 개인 라이프로그 앱. React + Vite로 만들고 Capacitor로 Android APK를 만든다.

예전 Life Log Planner 코드는 `legacy/`에 그대로 남겨 두었다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 모아 | 첫 화면. 지금 하는 일, 자주 쓰는 말 버튼, 모아의 대답과 되돌리기 |
| 오늘 | 24시간 격자(한 시간 = 가로 6칸). 계획·실행·지우개를 골라 문질러 칠한다 |
| 시계 | 진행 중인 일의 시계, 집중도 1~5, 같이 하는 일 |
| 기록함 | 하려던 일(말한 날 → 시작), 계획이 바뀐 흐름, 내가 한 말 원문 |
| 돌아보기 | 주간 적어둔 시간, 요일별 집중도, 하려던 일의 시작까지 걸린 기간 |
| 설정 | 활동 이름, 먼저 말 걸기 알림, 내보내기·가져오기, 전체 삭제 |

## 격자 규칙

- 계획: 칸 전체를 연하게 채운다. 칸당 1개.
- 실행 1개: 칸 높이의 80%.
- 실행 2개: 둘째가 아래 30%. 한 칸에 2개까지이고 세 번째를 칠하면 둘째가 바뀐다.
- 시간은 분·초 그대로 저장하고, 10분 칸은 보여주는 방식일 뿐이다 (`src/lib/intervals.ts`).

## 모아가 알아듣는 말

먼저 규칙으로 해석한다 (`src/lib/parser.ts`). 규칙으로 못 알아들은 말은, 설정에서 **AI로 알아듣기**를 켠 경우에만 서버(`server/`, Cloudflare Workers + Gemini)에 물어본다. 서버가 없거나 실패하면 메모로 남는다. 모든 말은 원문 그대로 바로 저장된다.

| 말 | 결과 |
|---|---|
| `과제 시작할게` | 타이머 시작 (동시에 2개까지) |
| `끝났어`, `수업 끝났어` | 타이머 종료 |
| `논문 써야지` | 하려던 일로 기록 (시작과 구분) |
| `하기 싫어` | 기분만 기록, 계획은 그대로 |
| `아까 14시부터 15시 반까지 알바 했어` | 지난 시간 채우기 |
| `나 잘게` / `일어났어` | 수면 시작·종료 |
| `집중도 4`, `피로도 80` | 점수 기록 |
| `말 걸지 마` | 먼저 말 걸기 끄기 |

## 폴더

| 경로 | 내용 |
|---|---|
| `src/` | 앱 (React). `lib/`가 기록 로직, `screens/`가 화면 |
| `server/` | AI 해석 서버 (Cloudflare Worker) |
| `android/` | Android 프로젝트 (Capacitor 8, 대상 API 36) |
| `assets/` | 아이콘·스플래시 원본 |
| `docs/` | 서버 연결, 출시 준비, 개인정보 처리방침, 스토어 문구 |
| `legacy/` | 예전 Life Log Planner 코드 |

## 개발

Node 22 이상이 필요하다.

```bash
npm install
npm run dev      # 브라우저에서 확인
npm test         # 기록 로직, AI 응답 처리, 서버 테스트
npm run build    # 타입 검사 + 빌드
```

## 빌드와 배포

| 무엇 | 어떻게 |
|---|---|
| 설치해 볼 APK | `moa`/`main`에 푸시 → Actions의 **Android CI** → Artifacts `app-debug-apk` |
| 스토어용 AAB | Actions의 **Release AAB** 직접 실행 (`docs/release.md`) |
| AI 서버 | Actions의 **Deploy API** (`docs/server.md`) |

디버그 APK는 저장소의 고정 키(`android/debug.keystore`)로 서명해서 새 빌드를 덮어 설치할 수 있다. 이 키는 시험용이며 비밀이 아니다. 스토어용 키는 저장소에 두지 않는다.

## 아직 없는 것

- 기기 간 동기화와 클라우드 백업 (수동 내보내기와 Android 자동 백업만 있다)
- GPS, 영수증·가계부, 사진, 키링 연동
- 일본어, 어두운 테마
- 실제 기기에서의 확인 목록은 `docs/release.md`에 있다
